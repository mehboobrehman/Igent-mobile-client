**Symbol:** CPHL | **Sector:** Pharmaceuticals

Citi Pharma makes active pharmaceutical ingredients (APIs), including paracetamol, as well as finished medicines. It is building API capacity to replace imports.

**Earnings drivers**
- API volumes.
- Pricing compared with imported APIs, which depends on PKR/USD.
- Expansion projects.
- Finance costs.
